标注含义说明

核心指标定义

判题正确率判题正确数 / 总题数 = 11/20 = 55.0%。无法判断(ungradable)计为错误，反映系统端到端真实表现
OCR失败率OCR完全无法识别(unreadable)题数 / 总题数 = 3/20 = 15.0%。手写涂改、字迹潦草导致模型读不出答案
AI推断答案错误率AI推断的正确答案本身有误的题数 / 总题数 = 2/20 = 10.0%。OCR正确读出学生答案，但AI求解题目时算错了正确答案
OCR偏差率OCR识别出内容但与真值不一致的题数 / 总题数 = 3/20 = 15.0%。模型识别出答案但存在系数、格式等偏差

表格列说明

CSV答案CSV文件中人工记录的学生实际作答
学生实际CSV中判题真值：学生实际答对(对)还是答错(错)
系统识别Qwen模型从图片识别的学生答案 (parsed.json → student_answer)
识别匹配=与CSV一致；偏差=识别出但内容不一致；失败=unreadable
系统判题GPT批阅模型的结论 (grading.json → judgement)：correct/incorrect/ungradable
最终结论正确=系统判题与学生实际对错一致；错误=不一致或ungradable（ungradable计为错误）
错误归因定位问题出在哪个环节：OCR失败、AI推断答案错误、GPT API不可用

错误归因分类说明

全链路正确OCR识别正确 → AI判题正确 → 结论与学生实际一致
OCR失败→无法批阅手写涂改/字迹潦草导致unreadable，系统无法进入批阅环节
AI推断答案错误→判题错误OCR准确读出学生答案，但AI推断的"正确答案"本身算错了，导致判题结论错误。
示例：初中Q6学生选B，AI推断正确答案也是B判定为correct，但实际B不是正确答案（学生实际答错了）
GPT API不可用→批阅失败OCR识别成功，但GPT fallback(codex)返回HTTP 503，批阅环节中断，结果为ungradable

OCR偏差 vs OCR失败

OCR偏差模型识别出了答案，但内容与真值不完全一致（如系数丢失、格式差异、数值偏移）。系统仍可进入批阅环节。
OCR失败模型完全无法识别答案，返回unreadable。系统无法进入批阅环节，直接判定为ungradable。
